# Contribute to the training materials

The Jupyter4NFDI training materials are openly available on GitHub. Feedback and improvements are welcome.

## Improve this training website

Use the [training repository](https://github.com/NFDI-Jupyter/training) to propose updates to the catalogue, navigation, descriptions, or appearance. You can [open an issue](https://github.com/NFDI-Jupyter/training/issues) or submit a pull request.

## Improve a particular module

Each module has its own repository. For corrections to a lesson or exercise, use the repository linked from the [module catalogue](modules.md). This keeps changes close to the source material.

## Suggest a new training topic

A useful suggestion describes the intended audience, the practical skill they would learn, and an example research workflow. Open an issue in the [training repository](https://github.com/NFDI-Jupyter/training/issues) to start a discussion.
