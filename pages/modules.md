# Training modules

These self-paced Jupyter Books cover individual tasks and skills. You can take them in any order. All modules are maintained in separate GitHub repositories, where you can also find the source files.

| Module | What you will learn | Materials |
| --- | --- | --- |
| [**Working with different programming languages and kernels**](https://nfdi-jupyter.github.io/learn-jupyter4nfdi-languages-kernels/) | Use different languages and manage kernels in Jupyter4NFDI. | [Repository](https://github.com/NFDI-Jupyter/learn-jupyter4nfdi-languages-kernels) |
| [**Prepare your project to be Jupyter4NFDI-ready**](https://nfdi-jupyter.github.io/learn-jupyter4nfdi-ready/) | Configure a repository for reproducible launches with repo2docker. | [Repository](https://github.com/NFDI-Jupyter/learn-jupyter4nfdi-ready) |
| [**Automated Notebook Validation**](https://nfdi-jupyter.github.io/learn-jupyter4nfdi-automated-validation/) | Run and validate notebooks automatically using GitHub Actions. | [Repository](https://github.com/NFDI-Jupyter/learn-jupyter4nfdi-automated-validation) |
| [**Working with external data storage**](https://nfdi-jupyter.github.io/learn-jupyter4nfdi-mouting-data/) | Mount external storage and access datasets from an environment. | [Repository](https://github.com/NFDI-Jupyter/learn-jupyter4nfdi-mouting-data) |
| [**Getting access to GPUs on Jupyter4NFDI**](https://nfdi-jupyter.github.io/learn-jupyter4nfdi-gpu/) | Request GPU access and learn when GPU acceleration is useful. | [Repository](https://github.com/NFDI-Jupyter/learn-jupyter4nfdi-gpu) |

## Choosing your next module

If you are new to Jupyter, start with [Getting started](getting-started.md). If you already have code or notebooks, the **Jupyter4NFDI-ready** module is a good place to begin. See the [learning paths](learning-paths.md) page for suggested combinations.
