# Getting started with Jupyter4NFDI

Jupyter4NFDI gives researchers access to interactive computational environments through the browser. You can use JupyterLab to work with notebooks, code, and data without configuring everything on your own computer.

## First steps

1. **Open the [Jupyter4NFDI Hub](https://hub.nfdi-jupyter.de/hub/home)** and sign in using an available identity provider.
2. **Launch an environment** using the options offered to your account.
3. **Explore JupyterLab.** Use the file browser, launcher, terminals, and notebook interface to get familiar with your workspace.
4. **Try a notebook.** Create or open a notebook, select a kernel, and run a code cell.
5. **Choose a training module** from the [module catalogue](modules.md) to work on a specific skill.

```{note}
The environments and resources available to you may depend on your account and access permissions. GPU resources require additional access; see the [GPU module](https://nfdi-jupyter.github.io/learn-jupyter4nfdi-gpu/).
```
